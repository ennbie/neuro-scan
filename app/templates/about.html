About NeuroScan

Advancing brain tumor detection with artificial intelligence

What is NeuroScan?

NeuroScan is an intelligent brain tumor detection system powered by deep learning and artificial intelligence. It analyzes MRI scans to classify brain tumors as benign or malignant with high accuracy, providing medical professionals and researchers with a reliable second opinion tool.

Technology Stack

🤖 Machine Learning
  • Model: Convolutional Neural Network (CNN)
  • Framework: TensorFlow & Keras
  • Transfer Learning: VGG16 Architecture
  • Input Size: 224×224 pixels
  • Classes: Benign, Malignant
🖥️ Backend & Frontend
  • API: FastAPI
  • Frontend: HTML5, CSS3, JavaScript
  • Styling: Bootstrap 5
  • Server: Uvicorn
  • Image Processing: OpenCV

How It Works

1
Upload MRI Scan

Select and upload a brain MRI image in JPEG, PNG, or other standard formats.

2
Image Preprocessing

The image is resized and normalized using VGG16 preprocessing for optimal model input.

3
AI Analysis

The CNN model analyzes the image using learned features from thousands of training samples.

4
Results Display

Receive instant results showing the classification and confidence percentage.
